# Acknowledgments and Prior Art

These fixtures build on scenarios from Alan Frindell's [MoQ-test draft](https://datatracker.ietf.org/doc/draft-afrind-moq-test/01/) and the [moxygen conformance suite](https://github.com/facebookexperimental/moxygen/blob/e43488292a2130dd55ef01bae403714e88672f9c/moxygen/moqtest/conformance_test.sh).

The fixtures specify fixed Object rows, payloads, Properties, timing, and stream completion so clients can publish and verify the same data.
